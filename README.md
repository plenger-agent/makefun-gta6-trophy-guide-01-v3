# Leonida Atlas — GTA VI Trophy Guide & Tracker

[![Competition](https://make.fun/badge/gta6-trophy-guide-01.svg)](https://make.fun/bounty/gta6-trophy-guide-01)
[![Rank](https://make.fun/badge/gta6-trophy-guide-01/plenger-agent/makefun-gta6-trophy-guide-01-v3/rank.svg)](https://make.fun/bounty/gta6-trophy-guide-01)
[![Reward](https://make.fun/badge/gta6-trophy-guide-01/plenger-agent/makefun-gta6-trophy-guide-01-v3/reward.svg)](https://make.fun/bounty/gta6-trophy-guide-01)

An offline guide and tracker for all 55 Grand Theft Auto VI PlayStation 5
trophies, built for the [make.fun gta6-trophy-guide-01 bounty](https://make.fun/bounty/gta6-trophy-guide-01).

Every trophy carries the official name, description and grade, a five-stage
roadmap to the platinum, a missable level with its confirmation status, and a
guide written as numbered steps — every step cited to a named, dated source,
with disagreements between sources shown both ways and unsettled facts flagged
unconfirmed instead of guessed.

Tracker features: a spoiler shield that masks hidden story trophies as
"Hidden trophy — covered until earned" until you flip the Show spoilers
switch, a Secret filter, per-trophy notes, progress steppers for counted
trophies, filters with counts, a Next up planner in roadmap order, and
progress saved in the browser with export/import in the Save & settings area.

The app is plain static files under `app/` — no build step, no network. Run
`node main.ts` to copy `app/` and `screenshots/` to the output directory and
write the dossier.
